## slims9plugins
A variety of plugins for SLiMS v9.x library software, particularly to support Myanmar languages. Each plugin folder should be placed in the **/plugins** directory of your SLiMS installation, and enabled as desired from the SLiMS *System->Plugins* menu option.

1. visitor_log_management . Adds a submenu item in the Master Files menu that assists deletion of visitor log records
2. slims_documentation . Adds a submenu item in the System menu that provides an offline searchable HTML manual for SLiMS, in English
3. slims_documentation-mya . Adds a submenu item in the System menu that provides an offline searchable HTML manual for SLiMS, in Myanmar language
4. biblio-addons-min . Opens a modal frame when accessing the Bibliography module of SLiMS. This contains quick launch buttons to access MLA suject Headings List, and a volatile scratchpad for temporary note-taking
5. biblio-addons-min-my_MM . Myanmar version of 4.
